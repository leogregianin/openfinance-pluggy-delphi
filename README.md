# Componente Open Finance para Delphi

## Menos OFX. Mais automação financeira - Se o seu ERP ainda não tem Open Finance, ele está na era dos dinossauros

Substitua o processo manual de baixar e importar arquivos OFX por uma conexão
autorizada com os bancos. A Pluggy conduz a conexão e entrega dados financeiros
em uma API unificada, pronta para o ERP consumir.

Com a Pluggy você tem mais de 220 instituições financeiras em uma única API,
combinando Open Finance e acesso direto. Em vez de criar e manter integrações
separadas para cada banco, sua equipe pode focar nas funcionalidades do ERP.

## Dados sob demanda
Consulte saldos, contas, cartões e transações pela API.
O retorno reflete os dados mais recentes disponibilizados pelo banco e
sincronizados pela Pluggy; a disponibilidade e a atualização variam por
instituição e pelo consentimento do usuário.

## O que a demonstração mostra

- Conexão bancária via Pluggy Connect, com autorização do usuário.
- Múltiplas instituições, identificadas por nome e logo.
- Contas, cartões, saldos, limites e transações.
